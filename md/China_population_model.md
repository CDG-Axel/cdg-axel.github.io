# Модель населения Китая до 2100 года

Версия 0.9, 2026-10-19. Рабочая страница: `china_population_model.html` (данные зашиты в объект `DATA`).

## 1. Цель и результат

Простая когортно-компонентная модель населения Китая, 2025–2100, шаг 5 лет, для сравнения с UN WPP 2024 и официальными данными КНР. По умолчанию все параметры постоянны; по желанию TFR и e0 можно вести по траектории. Расхождения с эталонами покажут, какие упрощения снимать в первую очередь.

Результат: одна HTML-страница. Настройки: TFR, e0 М/Ж; в «Дополнительных»: MAC, SD, SRB, NMR и три блока траекторий (TFR, e0 М, e0 Ж): флажок, значение 2100 года, затухание c (каждый блок оформлен рамкой с заголовком, например «Изменение TFR»). На графике линия ООН строится по всему годовому ряду. Вывод: карточки, график, таблица по периодам (родилось, умерло, миграция, население, женщины 15–49, доли 0–14 и 65+, а также TFR и e0 М/Ж в середине периода), кнопка «Скопировать JSON» (полная пирамида на каждом шаге и все параметры). Настройки хранятся в `localStorage` (только отличия от умолчаний; после смены умолчаний у тех, кто менял поля, старые значения остаются — «Сбросить» их убирает).

## 3. Метод

**Сетка.** Возрастные группы 0–4 … 95–99, 100+ (21 группа); шаг 5 лет, поэтому каждая группа за шаг целиком переходит в следующую.

**Рождаемость.** TFR постоянный, но число рождений зависит от числа женщин. ASFR — нормальное распределение (MAC, SD), усечённое до 15–49 и нормированное на TFR. Рождения за шаг = 5 · Σ ASFR_i · (женщин группы i в начале и конце шага, среднее). Мальчики/девочки по SRB.

**Смертность.** Берётся таблица WPP 2025 (m и q по возрастным группам) для каждого пола. В группе: умерло d = l·q, прожито человеко-лет L = d/m, дожило l − d; для открытой группы 100+ L = l/m. При базовых значениях это воспроизводит e0 WPP точно. Отсюда:
- e0 = ΣL (при начальном l = 1);
- коэффициент дожития группы за 5 лет S_i = L следующей группы / L текущей (для 0–4 берётся L(0)+L(1–4)); в группе 100+ остаются exp(−5·m);
- доля выживших новорождённых до конца шага = L(0–4)/5.

**Как смертность меняется с e0.** Задавая e0 мужчин и женщин, пользователь меняет не отдельные коэффициенты, а один множитель k: все m(x) данного пола умножаются на k, а q пересчитывается как 1 − exp(−n_eff·k·m), где n_eff = −ln(1−q)/m — «эффективная ширина» группы, взятая из WPP (около 5 лет, для старших групп меньше). Страница подбирает k делением пополам так, чтобы e0 таблицы сошлась с заданной. Следствия:
- e0 равна расчётной по таблице (75,65 / 81,25) → k = 1, данные WPP не меняются;
- e0 выше → k < 1 (смертность падает во всех возрастах пропорционально); e0 80,2 / 85,9 даёт k ≈ 0,660 (М) и 0,624 (Ж);
- e0 ниже → k > 1;
- k постоянен до 2100, т. е. e0 задаёт сдвиг смертности один раз, а не тренд.
Оговорка: равномерное масштабирование грубо (реальные улучшения неравномерны по возрастам); при необходимости заменим сдвигом по возрасту или траекториями WPP. Значения k показываются под таблицей и в JSON (`calibration`).

**Траектории TFR и e0.** Значения 2025 года — основные поля (TFR, e0 М, e0 Ж). Если у параметра включён флажок, его значение в середине каждого 5-летнего периода равно v₀ + (v₁ − v₀)·g(x), где v₁ — значение 2100 года, x = (год − 2025)/75, g(x) = (1 − e^(−c·x))/(1 − e^(−c)); при c = 0 это прямая, при c > 0 изменение быстрее в начале и медленнее в конце. Для TFR значение идёт прямо в ASFR; для e0 в каждом периоде заново подбирается k (см. выше). Значения по умолчанию подогнаны под ряды WPP 2024 medium: TFR 1,345 / c 1,45 (ошибка 0,002); e0 М 88,37 / c 1,10 и e0 Ж 91,37 / c 0,51 (ошибка около 0,15 года). Прямая линия на тех же рядах ошибается на 0,04 (TFR), 1,2 (М) и 0,5 (Ж) года.

**Миграция.** Сальдо NMR к каждой возрастной группе одинаково (в т. ч. новорождённым), без учёта пола и возраста.

**Шаг алгоритма:** смертность существующих групп → сдвиг → миграция → рождения → новая группа 0–4.

## 4. Упрощения

1. MAC, SD, SRB, NMR постоянны до 2100; TFR и e0 постоянны, если не включены траектории.
2. Смертность — WPP 2025 × общий множитель k (постоянный или идущий по траектории e0); без разной динамики по возрастам.
3. Закон Гомпертца–Мейкема пробовали — к данным Китая не подошёл, от него отказались.
4. Рождаемость — одно нормальное распределение; форма с годами не меняется.
5. Миграция однородна по возрасту и полу.
6. Шаг 5 лет, группы 5 лет; рождения и смерти внутри шага — по средним.
7. Охват и источники — как в WPP (без Гонконга, Макао, Тайваня).

## 5. Сравнение с UN WPP 2024

Результаты модели (млн человек, 2050 / 2100; эталон ООН 1 260,3 / 633,4):

| Сценарий | 2050 | 2100 |
|---|---|---|
| Базовый (TFR 0,995, e0 75,65 / 81,25) | 1 173,0 | 408,7 |
| TFR 1,3 | 1 230,2 | 567,5 |
| TFR 2,1 | 1 382,7 | 1 184,3 |
| e0 80,2 / 85,9 | 1 253,7 | 468,5 |
| TFR 1,3 и e0 +5 лет | 1 318,1 | 637,6 |

Главные выводы:
1. Главный рычаг — TFR; к 2100 разница от рождаемости (0,995 → 1,3) около +160 млн, от e0 (+5 лет) около +65 млн. Если TFR не растёт, а e0 растёт до уровня лучших стран (Гонконг около 85), население к 2100 остаётся около 410–470 млн.
2. Базовый вариант даёт к 2100 около 407 млн против 633 млн у ООН: ООН неявно предполагает рост TFR и e0.
3. Совпадение с ООН в 2100 достигается сочетанием TFR 1,3 и e0 +5, но тогда 2050 завышен на ~4,6 %: у ООН параметры меняются со временем, постоянные их не воспроизведут.
4. Остальные параметры слабее: MAC 27–31 даёт 390–425 млн, SD 4–6 — 407–411, SRB 110 — 405, NMR 0 — 416, NMR −1‰ — 385.

Траектории подтвердили гипотезу о причинах расхождения (млн человек, 2050 / 2100):

| Сценарий | 2050 | 2100 |
|---|---|---|
| Только TFR по траектории WPP (1,00 → 1,345) | 1 189,9 | 487,8 |
| Только e0 по траекториям WPP (М → 88,37, Ж → 91,37) | 1 233,2 | 552,4 |
| Обе траектории | 1 250,3 | 633,7 |
| UN WPP 2024 | 1 260,3 | 633,4 |

Модель с обеими траекториями почти совпадает с ООН (−0,8 % в 2050, +0,05 % в 2100). Расхождение с ООН объясняется двумя допущениями WPP: TFR растёт с 1,02 до 1,35 и e0 растёт до 88/91 лет. Если не принимать ни одно, население к 2100 около 410 млн; каждое из них по отдельности даёт +80 и +145 млн.

Дальше: сверить годовые ряды WPP (рождения, смерти, население, MAC, миграция) с моделью по траекториям и посмотреть, где остаётся расхождение.

## Глоссарий

| Термин | Смысл |
|---|---|
| WPP | World Population Prospects, прогноз ООН (ревизия 2024, medium variant) |
| TFR | Суммарный коэффициент рождаемости: среднее число детей на женщину |
| ASFR | Возрастной коэффициент рождаемости: рождений в год на женщину группы |
| MAC | Средний возраст матери при рождении; центр распределения ASFR |
| SD | Стандартное отклонение распределения ASFR, лет |
| SRB | Мальчиков на 100 девочек среди новорождённых |
| NMR | Чистая миграция, ‰ населения в год |
| e0 | Ожидаемая продолжительность жизни при рождении, отдельно для М и Ж |
| m(x) | Возрастной коэффициент смертности: смертей на человеко-год в группе (0,035 = 3,5 % в год у мужчин 70–74) |
| q(x,n) | Вероятность умереть в интервале n лет для дожившего до его начала; q ≈ 1 − exp(−n·m) |
| L | Человеко-годы, прожитые группой за шаг в таблице смертности |
| S | Коэффициент дожития группы за 5 лет |
| c | Затухание траектории: 0 — прямая, больше 0 — быстрее в начале и медленнее в конце |
| k | Множитель смертности: m → k·m; подбирается под заданную e0 |
