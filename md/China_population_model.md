# Модель населения Китая до 2100 года (v0)

Статус: черновик соглашений, есть рабочая страница `china_population_model.html`. Версия документа: 0.2. Дата: 2026-10-18.

Цель: собственное моделирование численности населения Китая с шагом 5 лет до конца столетия, для сравнения с прогнозом ООН и официальными данными КНР. Модель намеренно простая: все параметры в v0 фиксированы. Расхождения с эталонами покажут, какие упрощения нужно снимать в первую очередь.

---

## 1. Глоссарий

| Термин | Расшифровка | Смысл в этой модели |
|---|---|---|
| WPP | World Population Prospects (ООН) | Источник пирамиды и эталонного прогноза. Используется ревизия 2024, medium variant |
| Когортно-компонентный метод | Cohort-component method | Население делится на возрастные группы; каждый шаг группа «сдвигается» на следующую, из неё вычитаются умершие, добавляются мигранты, а рождения формируют новую младшую группу |
| TFR | Total Fertility Rate, суммарный коэффициент рождаемости | Среднее число детей на одну женщину за всю жизнь при текущих возрастных показателях рождаемости |
| ASFR | Age-Specific Fertility Rate | Число рождений в год на одну женщину данной 5-летней возрастной группы |
| MAC | Mean Age at Childbearing, средний возраст матери при рождении ребёнка | Центр нормального распределения рождаемости по возрасту |
| SD | Standard deviation, стандартное отклонение | Ширина нормального распределения рождаемости по возрасту (в годах) |
| SRB | Sex Ratio at Birth | Число мальчиков на 100 девочек среди новорождённых |
| e0 | Life expectancy at birth, ожидаемая продолжительность жизни при рождении | Средняя продолжительность жизни. По полу задаётся отдельно (e0 М, e0 Ж) |
| μ(x) | Force of mortality, интенсивность смертности | Мгновенный риск смерти в возрасте x |
| q | Вероятность умереть | Вероятность умереть в рамках шага (например, за 5 лет) для данной группы |
| S | Survival probability, вероятность дожить | S = 1 − q за шаг |
| Закон Гомпертца–Мейкема | Gompertz–Makeham law | μ(x) = A + B·exp(γ·x). A — «фоновая» смертность, не зависящая от возраста; B·exp(γx) — экспоненциальный рост смертности с возрастом |
| Td | Mortality doubling time | Время удвоения смертности. γ = ln 2 / Td. Базовое значение Td = 8 лет |
| NMR | Net Migration Rate | Чистая миграция (въезд минус выезд) в промилле (‰) или процентах от населения в год |
| CBR | Crude Birth Rate | Рождений на 1000 человек в год |
| CDR | Crude Death Rate | Смертей на 1000 человек в год |
| Nfa | Число женщин фертильного возраста (15–49) | Входит в расчёт числа рождений |
| Период | Интервал в 5 лет, например 2026–2031 | Строка итоговой таблицы |

## 4. Метод расчёта

### 4.1 Сетка

- 21 возрастная группа: 0-4, 5-9, ..., 95-99, 100+. Пол: отдельно М и Ж.
- Шаг по времени Δ = 5 лет равен ширине возрастной группы. За один шаг группа i целиком переходит в группу i + 1.
- Пирамида WPP соответствует середине года (1 июля). Учитывайте это при сравнении с эталонами.
- Базовый год — 2025. Сетка: 2025, 2030, ..., 2100 (15 периодов), конец последнего периода совпадает с 2100. Пирамида 2026 используется только для контроля.

### 4.2 Смертность

Для возрастов 30+ (группы 30-34 и выше):

    μ(x) = A + B · exp(γ · x),   γ = ln 2 / Td,   Td = 8 лет

- A — фоновая смертность, фиксированная константа (значение уточнить, п. 9, вопрос 2).
- B подбирается отдельно для М и Ж так, чтобы ожидаемая продолжительность жизни при рождении равнялась заданному e0 (бисекция).
- Для возрастов до 30 лет (группы 0-4 ... 25-29) используются фиксированные вероятности смерти за 5 лет q, взятые из таблицы смертности WPP (значения уточнить, п. 9, вопрос 2).

Вероятность дожить за один шаг для группы с возрастом [x, x + 5):

    S = среднее по a ∈ [x, x + 5) от exp( −∫ от a до a + 5 μ(u) du )

(численное усреднение по однолетним подшагам; равномерное распределение возрастов внутри группы).

Умершие группы за шаг: D = N · (1 − S). Группа 100–104 за шаг вымирает полностью (S = 0).

### 4.3 Рождаемость

Распределение рождаемости по возрасту — нормальное N(MAC, SD²), усечённое до 15–50 лет и нормированное.

1. Вес группы i (i = 15-19, ..., 45-49): w_i = Φ((b_{i+1} − MAC)/SD) − Φ((b_i − MAC)/SD), где b — границы группы; веса нормируются так, чтобы Σ w_i = 1.
2. ASFR_i = TFR · w_i / 5 (рождений в год на женщину группы i). Контроль: TFR = 5 · Σ ASFR_i.
3. Рождения за шаг: B = 5 · Σ ASFR_i · (F_i(t) + F_i(t + 5)) / 2, где F_i — число женщин группы i, а F_i(t + 5) считается без учёта новых рождений (зависит только от более старших групп).
4. Новорождённые: мальчики = B · SRB / (SRB + 100), девочки = B · 100 / (SRB + 100).
5. В группу 0-4 на конец шага попадает доля s_b от рождённых (дожившие до конца шага). Значение s_b вычисляется из q для группы 0-4 (по умолчанию s_b = 1 − q₀₋₄ / 2; уточнить в коде).

Решение по формулировке (закрыто в v0.2): TFR постоянен и от числа женщин не зависит. Число рождений пропорционально числу женщин фертильного возраста: B = Σ ASFR_i · F_i, то есть по сути B = K1 · Nfa, где K1 — число рождений на одну женщину 15–49 в год (разложено по возрастным группам). Чем меньше женщин, тем меньше рождений при том же TFR. Вариант «TFR сам пропорционален Nfa» отвергнут: он давал бы зависимость от Nfa² и самоусиливающееся падение, не имеющее демографического обоснования.

### 4.4 Миграция

Чистая миграция задана как доля от населения (NMR = −0,024% в год) и применяется к каждой возрастно-половой группе после учёта смертности:

    N_i(t + 5) = N_i^(после смертности) · (1 + NMR)^5

Миграция не меняет пол-возрастную структуру отдельно от населения. Смертность среди мигрантов внутри шага не учитывается.

### 4.5 Шаг алгоритма

Для каждого периода [t, t + 5):

1. Посчитать S для всех групп и полов.
2. Посчитать умерших D.
3. Сдвинуть выживших в следующую группу, применить миграцию.
4. Посчитать рождения B и заполнить группы 0-4 (М и Ж).
5. Записать строку результата: годы, рождения, умершие, миграция, население, доли групп.

## 5. Упрощения v0

Все параметры постоянны до 2100 года. Направления для усложнения указаны в скобках.

1. TFR = 0,995 неизменен (нужна зависимость от времени и политики).
2. MAC и SD неизменны (сдвиг среднего возраста матери вверх — первое усложнение).
3. Форма распределения рождаемости — нормальная, симметричная (реальная асимметрична).
4. SRB = 105 для всех лет (в реальности около 109,3 по данным WPP; решение — считать, что сдвиг, вызванный селективными абортами, исчез).
5. Смертность по возрастам и полам зафиксирована на уровне текущего e0 (рост или падение e0 не моделируется).
6. Закон Гомпертца–Мейкема с Td = 8 для возрастов 30+; для 0–30 фиксированные коэффициенты.
7. Предельный возраст 105 лет; группа 100+ трактуется как 100–104.
8. Миграция — постоянная доля населения, одинаковая для всех возрастов и полов (структура мигрантов и политика не учитываются).
9. Внутри 5-летнего шага возрасты в группе распределены равномерно.
10. Нет эффектов эпидемий, войн, технологических скачков, изменений в системе здравоохранения.
11. Охват: только материковый Китай (без Гонконга, Макао, Тайваня).
12. Рождения пропорциональны числу женщин 15–49 при постоянном TFR (зависимости TFR от численности нет).
13. Для групп до 30 лет и для фоновой смертности A используются плейсхолдеры (п. 3.2).

## 6. Предварительная проверка (на данных пирамиды 2026)

Грубый прогон до написания кода, чтобы заранее видеть порядок величин.

**Рождаемость.** При TFR = 0,995 и MAC = 29,15 число рождений в год:

| SD, лет | 4,5 | 5,0 | 5,5 | 6,0 |
|---|---|---|---|---|
| Рождений в год, млн | 8,23 | 8,30 | 8,37 | 8,42 |

Чувствительность к SD небольшая (около ±1%). Для сравнения: средняя группа 0-4 в пирамиде 2026 (45,05 млн за 5 лет) соответствует примерно 9,0 млн в год, но эта группа родилась при более высоком TFR (2021–2025).

**Смертность.** Чистый закон Гомпертца с Td = 8 лет (без детского блока), подогнанный под e0: 75,2 (М) и 80,9 (Ж), даёт на пирамиде 2026 года (A — фоновый член):

| A, в год | Смертей в год М, млн | Ж, млн | Всего, млн |
|---|---|---|---|
| 0 | 7,91 | 6,20 | 14,11 |
| 0,0003 | 7,60 | 5,92 | 13,52 |
| 0,0005 | 7,40 | 5,75 | 13,14 |

Это заметно выше официальных данных (порядка 11 млн в год; цифра по памяти, требует проверки по НБС и WPP). Значит, пара «Td = 8 лет + e0 из World Bank» на данной пирамиде, скорее всего, завышает смертность на 20–25%. Это первая точка, которую надо разобрать при валидации (проверить Td, e0, влияние блока до 30 лет, период e0 и его соответствие пирамиде).

**Миграция.** −0,24‰ от 1,413 млрд — около −339 тыс. человек в год.

## 9. Открытые вопросы

Решения v0.2: базовый год — 2025 (п. 1); плейсхолдеры для блока до 30 лет и A приняты (п. 2); SD = 5,0 и SRB = 105 приняты (пп. 3, 4); формулировка K1 закрыта (п. 8). Остаются пп. 5, 6, 7.

1. **[закрыт: базовый год 2025] Базовый год.** Данные у нас на 2026, а задача сформулирована «с 2025 до 2100». При шаге 5 лет и старте 2026 сетка идёт 2026, 2031, ..., 2096, 2101, то есть 2100 попадает внутрь последнего шага (сравнение с WPP возможно через интерполяцию). При старте с пирамиды 2025 сетка заканчивается ровно в 2100. Рекомендация: взять пирамиду 2025 той же выгрузкой (https://www.populationpyramid.net/china/2025/), а данные 2026 оставить для контроля. Решение не принято.
2. **[плейсхолдеры приняты] Фиксированные коэффициенты для 0–30 лет и A.** Нужны q по группам из таблицы смертности WPP 2024 для Китая (по полу). Пока значения не получены. Для старта: A = 0,0003 в год (плейсхолдер, только для отладки), q₀₋₄ ≈ 0,007 (плейсхолдер по памяти, проверить).
3. **[принято] SD = 5,0.** Предложение, не подтверждено; влияет слабо (см. п. 6).
4. **[принято] SRB.** Принято 105 (естественное значение). Мировое среднее в статистике ООН чуть выше из-за Китая и Индии, поэтому «как в среднем по миру» трактуется как естественное значение 105. Подтвердить.
5. **Невязка по смертям** (п. 6): модель завышает число смертей. Разобрать на этапе валидации, не подгонять заранее.
6. **Период e0.** World Bank даёт e0 за 2023 год; пирамида — на 2026. Возможно, лучше использовать e0 из WPP на 2026 год.
7. **Округление пирамиды.** Расхождение суммы колонок с итогом сайта — 12 человек, на модель не влияет.
8. **[закрыт] Формулировка K1.** Подтвердить трактовку B = K1 · Nfa (рождения на одну женщину фертильного возраста постоянны), см. п. 4.3.
