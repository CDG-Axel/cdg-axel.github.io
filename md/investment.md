# Планировщик регулярных доходов

Инструмент для отслеживания и прогнозирования доходов от нескольких источников на временной шкале.

## Что показывает страница

Сводка вверху отображает суммарный доход в текущем месяце и прогноз на 3 месяца вперёд. В строке «Проблемные источники» — те, у которых срок уже истёк или истекает в течение 30 дней.

Таблица-шкала охватывает 7 месяцев: предыдущий, текущий и 5 следующих. Каждая строка — один источник, каждая ячейка — полоска активности за этот месяц. Ширина полоски отражает долю месяца, в которую источник активен; число внутри — пропорциональный доход за этот период. Текущий месяц выделен цветом.

Цвет полоски зависит от статуса источника на текущий момент:
- без цвета (зелёный фон) — источник активен, до окончания больше 30 дней
- жёлтый — истекает в течение 30 дней
- красный — срок уже истёк
- серый — ещё не начался

Строка «Итого» показывает суммарные вложения и ожидаемый доход по всем источникам типа «Инвестиция».

## Первый запуск

Если сохранённых данных ещё нет, страница показывает демонстрационные источники: ежемесячные и инвестиции, активные, скоро заканчивающиеся, завершённые и ещё не начавшиеся. Это примеры, чтобы было видно возможности приложения. Их можно отредактировать или удалить. Пока вы ничего не изменили, примеры не сохраняются и при следующем открытии строятся заново относительно текущей даты. После первого изменения сохраняется уже ваш набор.

## Типы источников

**Ежемесячный** — повторяющийся доход: зарплата, аренда, пенсия. Указывается сумма за месяц. Дата окончания необязательна.

**Инвестиция** — разовое вложение с фиксированным сроком: депозит, облигации. Указывается вложенная сумма, ожидаемый суммарный доход за весь срок и обязательная дата окончания.

## Добавление и редактирование источников

Нажмите кнопку **+** для нового источника. Чтобы изменить существующий — кликните на иконку карандаша в строке таблицы.

Набор полей формы зависит от выбранного типа:

| Поле | Ежемесячный | Инвестиция |
|---|---|---|
| Название | ✓ | ✓ |
| Сумма в месяц | ✓ | — |
| Вложенная сумма | — | ✓ |
| Ожидаемый доход (за весь срок) | — | ✓ |
| Дата начала | ✓ | ✓ |
| Дата окончания | необязательно | обязательно |

## Удаление с возможностью отмены

Если источник удалён случайно, его можно вернуть кнопкой **↺** в шапке.

## Синхронизация вкладок

Если страница открыта в нескольких вкладках, изменения из одной автоматически применяются в остальных при возврате к ним.

## Экспорт и импорт

Данные хранятся в браузере (localStorage). Для переноса на другое устройство или резервной копии используйте меню **☰**:

- **Экспорт конфига (файл)** — сохраняет JSON-файл на устройство
- **Импорт конфига (файл)** — загружает ранее сохранённый файл
- **Экспорт/импорт (буфер обмена)** — копирует или вставляет конфиг как текст, удобно для быстрой передачи

Если файл или текст не удалось прочитать (повреждён, не хватает обязательных данных), появится сообщение об ошибке, а текущие данные останутся без изменений. Успешный импорт полностью заменяет текущий набор источников.

## Аналитика и cookie

При первом посещении внизу страницы появляется баннер: страница использует Google Analytics (cookie), чтобы понимать посещаемость и типы устройств. Аналитика включается только после нажатия **«Принять»**; при **«Отклонить»** ничего не загружается. Выбор запоминается в браузере.

Чтобы изменить решение, выберите в меню **☰** пункт **«Сбросить выбор по cookie»**: страница перезагрузится, и баннер появится снова.
